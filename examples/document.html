Document Design System

A plain HTML example of the sorafujitani.me theme.

Getting started

  1. Load the stylesheets.
  2. Add the sora-theme and sora-prose classes.
The theme does not set the page width or navigation.
<body class="sora-theme">
  <main class="sora-prose">Your content</main>
</body>
